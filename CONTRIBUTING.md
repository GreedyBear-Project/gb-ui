# Contributing

This is an internal fork of [certego/certego-ui](https://github.com/certego/certego-ui), maintained for use in the [GreedyBear](https://github.com/GreedyBear-Project/GreedyBear) project. It is not published to npm and has no outside consumers.

Issues and pull requests are welcome, but there is no CLA and no formal release process — changes land on `main` and GreedyBear pulls them in directly.
